# NorthWind-Sales-Analysis
🚀 Transforming Raw Data into Insights: Northwind Sales Analysis using DAX
Body:
Excited to share my latest project where I deep-dived into the Northwind Database to solve real-world business problems using Power BI and advanced DAX functions.
Instead of just creating visuals, I focused on the "Logic" behind the data. In this video presentation, I have demonstrated how to write optimized DAX queries to extract meaningful insights.
🔍 Key Business Questions Solved:
✅ Customer Analysis: Tracking specific orders for customers like 'Hanna Moos'.
✅ Product Insights: Identifying products within specific order IDs (e.g., 11011).
✅ Time Intelligence: Analyzing orders between specific date ranges.
✅ Geographical Growth: Counting orders country-wise to track market reach.
✅ Top Performers: Using TOPN to find the Best Selling Products & Categories.
✅ Sales Performance: Calculating total sales volume across the database.
🛠 Tools & Skills Used:
Power BI Desktop (Data Visualization)
DAX (Data Analysis Expressions): Used functions like CALCULATE, FILTER, RELATED, SUMMARIZE, TOPN, and CROSSJOIN.
Data Modeling & SQL Logic
This project helped me strengthen my logical thinking and problem-solving skills in Data Analytics.
